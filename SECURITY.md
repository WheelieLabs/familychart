# Security

FamilyChart handles health-related data. Please **do not** report security vulnerabilities in public GitHub issues, discussions, or pull requests.

## Reporting a vulnerability

Use one of the following private channels:

1. **GitHub private vulnerability reporting** — on the public repository, open **Security → Report a vulnerability** (preferred when available).
2. **Email** — [security@wheelielabs.com.au](mailto:security@wheelielabs.com.au)

Include a clear description, steps to reproduce, and the version or commit you tested against. We aim to acknowledge reports within a few business days.

## What to expect

- We will work with you to understand and validate the issue.
- We will not disclose your identity without your permission.
- We will coordinate disclosure timing once a fix is available.

## Scope

This policy covers the FamilyChart application source published under AGPL-3.0. It does not cover third-party hosting environments, misconfigured deployments, or separate commercial products (for example SupportChart or managed-hosting operations tooling).
